1. EXECUTIVE SUMMARY & EXPERIMENTAL DESIGN
--------------------------------------------------------------------------------
The objective of this research is to evaluate multiple foundational architectures
as dedicated "Universal Grugifiers"—cognitive translation engines that take raw,
verbose, discursive Chain-of-Thought (CoT) trajectories from any model and distill
them into ultra-dense, invariant-anchored Grug Speech (<think>...Done.</think>)
formatted for downstream Energy-Based Fine-Tuning (EBFT).

To determine the optimal Grugifier backbone, we evaluated three distinct base
architectures under identical fine-tuning regimens on an NVIDIA A100 GPU:

1. Model 1: Qwen2.5-3B-Instruct (Flagship High-Capacity Grugifier)
   - Parameters: 3.09 Billion
   - Architecture: Qwen2 Causal LM, 36 layers, SwiGLU, ChatML
   - Role: High-capacity multi-lingual, multi-domain cognitive compiler.
   - Status: Fine-tuned, validated (eval_loss: 0.000135), published to Hugging Face:
     https://huggingface.co/Novasaki/Qwen2.5-3B-UniversalGrugifier

2. Model 2: Qwen2.5-1.5B-Instruct (Edge & Mobile Grugifier)
   - Parameters: 1.54 Billion
   - Architecture: Qwen2 Causal LM, 28 layers, SwiGLU, ChatML
   - Role: Ultra-low latency, mobile/embedded edge Grugifier.
   - Target Repository: Novasaki/Qwen2.5-1.5B-UniversalGrugifier

3. Model 3: SmolLM2-1.7B-Instruct (Open LLaMA Architecture Grugifier)
   - Parameters: 1.71 Billion
   - Architecture: LLaMA3 Causal LM, 24 layers, Grouped-Query Attention (GQA)
   - Role: Cross-architectural validation on open LLaMA-based foundations.
   - Target Repository: Novasaki/SmolLM2-1.7B-UniversalGrugifier

4. ARCHITECTURAL COMPARISON & GPU EJECTION PROTOCOL
================================================================================
To prevent cross-contamination of CUDA memory, each model undergoes strict
isolated execution:

1. Setup: Load base weights in BF16 NF4 QLoRA on single A100 GPU.
2. Train: 150 optimization steps with cosine learning rate schedule (2e-4).
3. Eval: Compute validation loss and save adapter artifacts.
4. Eject: Explicit GPU ejection:
   - del model, trainer
   - gc.collect()
   - torch.cuda.empty_cache()
   - torch.cuda.ipc_collect()
   - Verified 0 MiB VRAM via nvidia-smi.
5. Upload: Publish to Hugging Face under Novasaki organization.
